# 五线速读 SightFlash

> 把「五线谱 ↔ 音名 ↔ 琴键」练成条件反射的**识谱反应训练器**。
> 纯前端 PWA，手机即开即用、可离线安装，练习数据全部存在本地。

**🎮 线上直接玩：<https://michael-miao99.github.io/sightflash/>**

手机浏览器打开即练；建议横屏 + 「添加到主屏幕」装成 PWA。跟着真琴练就用 **麦克风**（起音判定）或 **MIDI 键盘**（Android Chrome / 桌面 Chrome·Edge）。

---

## ✨ 功能一览

### 认音训练
- 看谱 → 点 **音名按钮** 或 **仿真钢琴琴键** 作答（琴键可听钢琴音）
- 难度阶梯 **S1–S5**，高音 / 低音 / 混合谱式随准确率解锁推进
- 混合谱式为真钢琴**大谱表**：双行五线 + 贯通大括号 + 高低双谱号同屏
- **练黑键**开关：补入升降号、谱面画 ♯/♭、12 键音名板
- 错音加权复习、打卡 / 连击、速度曲线与准确率、本地数据（IndexedDB，断网可用、数据不丢）

### 跟弹 —— 真琴弹奏与认音同屏
- 练习屏内一键开「**跟弹**」：当场授权麦克风，以**起音判题**（纯自研 YIN 音高检测，±30 音分）
- 真实琴弹奏与屏上点按统一按「**首击成败**」：第一次作答定此题——对了推进、错了可试弹不扣分、可换题；判对绿 ✓ 停留约 0.35 s 再换题，上一音余音不会误判成下一题
- 授权被拒 / 麦克风中段 → 跟弹自动关回并提示，本轮认音不被打断

### MIDI 键盘作答
- **Android Chrome**（OTG 线 / 蓝牙）或**桌面 Chrome / Edge** 接键盘，跟弹**自动优先用 MIDI**，无设备时回落麦克风
- 跟弹中拔掉键盘 → 自动切回麦克风并提示；重插后下一轮自动用回 MIDI
- iPhone Safari 无 Web MIDI → 设置页显示「此浏览器不支持」，跟弹走麦克风

### 外观与手感
- **四套主题**：暖纸乐稿（默认）/ 乌木暖夜 / 极简墨白 / 经典深色，谱面与琴键随主题自适应
- **麦克风灵敏度**设置页滑杆可调（吵闹环境 / 不同琴音量都能校准）

## 🧱 项目结构

| 目录 / 文件 | 职责 |
|---|---|
| `src/core/` | 纯逻辑，无 DOM：曲目生成 `generator`、判题状态机 `session`（`answerFirstShot` 统一首击入口）、存储抽象 `storage/` |
| `src/ui/` | 浏览器胶水：`StaffView` 谱面、`PracticeScreen` 练习屏（跟弹 / MIDI 输入源仲裁）、`micSource` 麦克风、`midiSource` MIDI 键盘 |
| `src/app/` | React 壳 + 视图路由；`playFlow` 一轮练习的调度（开始 / 首击 / 结算） |
| `scripts/` | `deploy-pages.mjs` 发布、`gen-icons.mjs` PWA 图标 |
| `docs/superpowers/specs/` | 设计文档（§1–§29 里程碑推进记录） |

技术栈：React 19 · Vite · TypeScript(strict) · vitest(jsdom) · vite-plugin-pwa(PWA) · idb(IndexedDB)。

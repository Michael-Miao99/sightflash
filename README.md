# 五线速读 SightFlash

把「五线谱 ↔ 音名 ↔ 琴键」练成条件反射的识谱反应训练器（PWA，手机可用）。

## 里程碑 A：认音模式
看谱 → 点音名按钮或仿真钢琴琴键（可听该音钢琴音）。难度阶梯 S1~S5、错音加权复习、打卡/连击、速度曲线与准确率、本地数据（IndexedDB）。
提示：手机建议横屏使用（Android 安装 PWA 后自动横屏；iPhone 旋转即可）。仿真键盘固定为 C2~C6 四个整八度、不随谱号移位，中央 C 键标文字「C4」。横屏下练习屏整屏放全、无纵向滚动，键盘高度随屏高自适应。设置页可开「练黑键（变化音）」：开后在当前音域补入升降号、谱面画 ♯/♭、音名板扩成 12 键（黑键键双名标注）。设置页另可切「主题」四套皮肤——暖纸乐稿（默认，米白谱纸 + 墨色，谱面随主题反色）/ 乌木暖夜 / 极简墨白 / 经典深色：选择即时生效并记住，谱面与琴键颜色随主题自动适配。混合模式（高/低混合）谱面为真钢琴大谱表：双行五线 + 贯通大括号 + 高/低音谱号同屏，单音画在所属那一行；高/低音单谱模式仍为单行谱。

## 里程碑 B（当前）：跟弹开关 —— 真琴弹奏与认音同屏，麦克风音高判定（纯自研 YIN）
认音与跟弹共用**同一练习屏**（谱面 + 反馈 + 音名板 + 仿真琴键，界面无差别），屏内「跟弹」开关是唯一入口。开关开 → 当场请求麦克风授权并监听真琴：以起音判题（YIN，±30 音分），且**真琴弹奏与屏上点按统一按「首击成败」**（第一次作答定此题：对了推进、错了可试弹不扣分、[下一题] 可换题）；判对显示绿✓ 并**短暂停留（≈0.35s）再换题**，上一音余音不会误判成下一题；不显示实时听音读数（音名/音量一律不出）。开关关 → 认音计分逐字保持里程碑 A 原样。数据页仍按「全部 / 认音 / 跟弹」筛选，**该轮开过跟弹即记「跟弹」、否则记「认音」**；授权被拒 / 麦克风中断 → 开关自动关回并提示，本轮认音不被打断、不提前结算。
设计文档：`docs/superpowers/specs/2026-09-05-sightflash-design.md`

## 真机验收清单（里程碑 A）
- [ ] 手机浏览器打开 https 页面（认音模式无需麦克风）
- [ ] 首页 → 开始训练 → 选高音谱 → 练一轮：谱面渲染正确、点音名判对/错、到点自动结算
- [ ] 答错后「常错音符」出现该音；重复练到准确率 ≥85% 自动升 S2（低音谱解锁）
- [ ] 混合模式（S3 后）：谱面为真钢琴大谱表（双行五线+贯通大括号+高低双谱号同屏），单音画在所属行、另一行只示空谱
- [ ] 混合模式换谱时键盘不随谱切换（固定 C2~C6 四整八度），中央 C(C4) 位置不动且白键下缘标文字 "C4"，横屏 29 白键仍可手按
- [ ] 开「练黑键」后同一轮能碰到升降号：谱面记号清晰、12 键音名板与仿真琴键黑键都能答对；关掉回到 7 键纯自然音
- [ ] 今日目标随正确数累加、跨天清零；连续天数正确累计
- [ ] 「添加到主屏幕」安装为 PWA；断网重开仍可用、数据不丢
- [ ] 横屏练习屏整屏可见、**无纵向滚动**；键盘高度随屏高自适应（矮屏不压垮）
- [ ] 混合模式 360 横屏：大谱表可读、双谱号/大括号清晰、键盘仍完整无纵向滚动
- [ ] 数据页速度曲线 / 错音分布与练习记录一致

> 真机验收需经 **https** 访问构建产物：`npm run build` 后把 `dist/` 伺服成 https（service worker 仅在 production 构建生效；可用 cloudflared 隧道等，见设计文档 §16）。

## 真机验收清单（里程碑 B·开关版，§28）
> 真机验收需经 **https** 伺服构建产物（同里程碑 A 说明：`npm run build` 后把 `dist/` 伺服成 https，service worker 仅 production 生效）。麦克风授权/起音判定只在 https（安全上下文）或 localhost 生效。
- [ ] 首页 → 开始训练 → 选谱号直进练习（**无「模式」分段、无校准页**）；界面默认认音：音名板 + 琴键可点、到点自动结算
- [ ] 练习屏表头点「跟弹」开关 → 出现麦克风授权；允许后开关保持开、**界面与认音无差别**（音名板/琴键仍在，不显示「现在听到/音量」）
- [ ] 真琴弹对谱面音 → 绿✓ 停留约 0.35s 再换下一题；上一音没弹完/余音不会被判成下一题错
- [ ] 真琴弹错（含同音名高/低八度）→ ✗ 并停留、可再弹试对（不扣分）、[下一题] 可换题；**低音 G2** 一带重点试（确认识别不锁高一八度）
- [ ] 跟弹开着时点屏上音名/琴键也按「首击成败」判（首击错试错不重计）
- [ ] 拒权 / 练习中切后台麦克风中断 → 开关自动关回 + 提示，本轮继续认音、**不提前结算**
- [ ] 到点结算进结果页：开过跟弹记「跟弹」、纯认音记「认音」；数据页曲线与练习记录一致
- [ ] 跟弹练习结束返回后浏览器麦克风指示灯熄灭（流已释放）；吵闹环境/踩踏板连音判定不疯跳（起音门抑制）
